Games

Black bars on the sides?

Some ROMs keep the picture's shape when the display size changes, so they add black bars instead of stretching. wm size alone can't change that. The CODM Stretch Hook (LSPosed, System Framework scope) replaces the bars with a real stretch. Check Fill hook in Status: it must say Loaded. Press Test 10s to see the result on this page.
