# CODM Ultra Stretch v1.15-universal

## What's included
- **CODM_Control.apk** — companion WebView app
- **CODM_Ultra_Stretch_v1_15_universal.zip** — Magisk / KernelSU module

## Installation
1. Backup existing config (`/data/adb/codm_stretch/`)
2. Remove older conflicting modules
3. Flash the ZIP → reboot
4. Open CODM Control or the WebUI (`http://127.0.0.1:8088/`)

## Safety
- Keep CPU/GPU controls disabled at first
- Confirm the module restores values when the game leaves foreground
